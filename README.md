## Admin fee reports

The Reports page downloads an Excel workbook for one or more selected classes,
filtered by paid or pending status. Only active students are included. Status
uses the Fees page's outstanding balance through the current month, including
arrears. Pending reports show that balance; paid reports show the Fees page's
paid summary. The paid summary includes successful active payments whose first
covered month falls between the student's fee start and the current month; a
payment covering future months is included in full.
